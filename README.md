# Cat_Filmes
Atividade de bibliotecas de componentes visuais com Expo e React Native Paper
1. Identificação da biblioteca
Nome: React Native Paper
Objetivo: A React Native Paper é uma biblioteca de componentes visuais para React Native. Ela oferece elementos prontos para criar interfaces de aplicativos móveis com aparência baseada no Material Design.
Documentação oficial: https://callstack.github.io/react-native-paper/
Repositório oficial: https://github.com/callstack/react-native-paper
2. Principais funcionalidades
A biblioteca disponibiliza componentes visuais reutilizáveis, que podem ser personalizados e combinados para formar telas de aplicativos.
No projeto CineLista, serão utilizados:
- Appbar: barra superior com o título e ações do aplicativo.
- Card: cartão para organizar informações de cada filme.
- TextInput: campo para digitar o nome e o gênero do filme.
- Button: botão para cadastrar filmes e navegar entre telas.
- Checkbox: opção para marcar um filme como assistido.
- Chip: pequeno elemento visual para destacar informações, como o gênero do filme.
- Snackbar: mensagem temporária para informar o resultado de uma ação.
3. Projeto escolhido
O aplicativo de exemplo será o CineLista, um catálogo pessoal de filmes. O usuário poderá cadastrar filmes, visualizar os itens em uma lista e marcar quais já assistiu.
